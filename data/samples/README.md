# Tiny sample data

These two records are here so the file format feels real:

- `train.jsonl` has one example the adapter may see
- `eval.jsonl` has one different example kept aside for comparison
- `images/` holds the files named in those records

This is enough to walk through the code, but not enough to teach a useful fashion model. Replace all of it for a real project, and only train on images you have permission to use.
